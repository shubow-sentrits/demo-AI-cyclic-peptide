小分子、环肽、蛋白设计共享什么？

三者都可采用配体数据驱动、靶结构驱动、生成后打分、局部优化与实验反馈。区别首先来自设计对象的表示与化学空间：小分子常用 SMILES/原子图，蛋白常用序列与残基骨架，环肽同时需要残基语义、共价闭环、立体化学与多构象。

因此，小分子生成器的合法 SMILES 不保证环肽的低应变闭环；蛋白设计器的高置信结构也不保证它能表达 N-甲基化或 D 残基。环肽路线经常需要在两套方法之间搭桥。[R01] [P10]

为什么不能只按“开源 / 闭源”选？

开源降低模型获取门槛，但目标准备、环境复现、筛选、合成、实验和迭代仍需投入。闭源服务可能缩短部署时间，却需要明确候选结构能否导出、版本能否固定、数据是否被留存以及产物权利。

PDPS、Bicycle 和 Insamo 更接近实验/资产平台；Schrödinger 是工具供应商；Latent 的模型服务和 agent 又是另一种交付。比较时先写出买到的交付物与可复核证据。

本项目的优先关注组合

复现基线：RFpeptides + AfCycDesign，配合 BoltzGen 对比。化学与性质补强：PepINVENT / RINGER，关注 CycloPepper 的合成数据逻辑。商业参照：Latent-X2 的托管生成、PDPS / Bicycle 的实验发现、Insamo 的数据闭环。待核实：CycleDesigner 原论文与 FlexRibbon 的环肽能力。

这是研究优先级，不是采购或投资结论。真正的优胜路线应在共同靶点、相同化学约束、相同送测预算下，由前瞻实验决定。

03 / 把生成候选变成学习过程

干湿闭环的价值，来自每一轮能修正什么。

定义可测目标→设计并选择→合成与确认→结合 / 功能 / ADME→更新数据与下一轮

从“分数表”升级为“实验可追溯记录”

分子记录至少包括序列、残基到原子的映射、闭环原子、立体化学、纯度及批次。运行记录保存输入结构、模型和权重版本、随机种子、筛选阈值与人工排除原因。

实验记录保留测定类型、单位、批次、浓度区间、重复和检测下限。合成失败、无法溶解、信号受干扰与真阴性应分开；否则模型会学到错误标签。

计算调用做成可重试的独立步骤，按候选长度/成本批处理；失败重跑无需抹掉旧结果。GPU 利用率是工程指标，每个可确认 hit 的总成本才接近项目指标。

Active Learning 具体选择什么？

下一批候选同时考虑预期收益、模型不确定性、结构/化学多样性和合成难度。已有高分候选用于利用，陌生但可测的骨架用于探索；两者比例应随预算和模型校准调整。

不要把预测器认为的“更好”当成新实验标签。真实测量进入训练集后，仍需保留独立时间/骨架测试集；同一骨架的近重复序列跨训练和测试会夸大效果。

建议先用一个低成本、可复测的基准 assay 建立闭环，再增加多目标。连续几轮只提高离线分数、却未改善实测结果，就应调整路线。

检查点输入 → 输出关键误差 / 对照预算位置
结构预测 / Docking分子与靶结构 → 复合物假说与分数环构象、口袋/界面状态、质子化；做已知对照及独立模型检查适合大批量前筛；成本依实现而变
MD / 构象采样参数化体系 → 轨迹 / 构象分布估计力场、初始构象、采样不足；多起点/重复与收敛检查用于代表性候选；时间尺度决定成本
MM-GBSA / FEP轨迹或配对分子 → 端点能量 / 相对自由能估计前者近似与熵遗漏；后者参数、拓扑变换、相空间重叠及慢构象转换FEP 往往留给较小、可比较系列；不是全库默认打分
合成与分析化学定义 → 确认身份/纯度的实物位点、异构体、难纯化；记录尝试数和失败原因不只算单体价格，也算工时、纯化与重复
SPR / BLI + 正交实验确认候选 → 结合曲线 / Kd 或动力学参数非特异结合、聚集、固定化与质量传递；使用空白/反选/重复可先快速筛查，再对少量候选做完整曲线
功能 / 通透 / 稳定性 / PK候选及目标相关体系 → 多项测量区分结合、抑制、胞质可达与系统暴露；不同 assay 不直接混为标签按治疗目的逐级投入，并行早测关键硬约束

物理计算误差见 R05；通透/口服边界见 R02、R06。成本描述是定性规划，不是厂商报价；实际需按靶点大小、硬件、候选数量与实验协议估算。

一个简单的漏斗检查

只用于理解分母。下面是教学假设，可修改；不是行业平均命中率。

面试中应当能明确回答的四件事

  1. 为什么选这条路线：靶点、给药路径、现有 hit/结构和可用实验，分别提供了什么条件？
  2. AI 到底贡献了什么：相同实验预算下，相对简单基线，增加了多少可确认 hit 或有效 SAR？
  3. 哪里仍有风险：化学范围、通透、合成与目标转化风险，下一轮哪个实验最能减少不确定性？
  4. 怎样形成持续优势：版本化流程、可用负样本、可靠 assay、可学习的化学系列及跨轮决策；不要只用“接了几个模型”解释壁垒。
